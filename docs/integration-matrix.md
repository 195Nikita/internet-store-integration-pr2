# Матрица артефактов и протоколов

| Компонент-источник | Компонент-приемник | Уровень | Протокол | Формат / артефакт | Назначение |
|---|---|---|---|---|---|
| Складская система | Адаптер импорта | Данные | SFTP | CSV / XML / JSON | Передача каталога, цен и остатков |
| Интернет-магазин | API-адаптер | Интерфейсы | HTTPS webhook | JSON | Передача нового заказа |
| API-адаптер | Бизнес-логика | Бизнес-логика | Внутрипроцессный вызов | Объект `Order` | Валидация и маршрутизация заказа |
| Бизнес-логика | Учетная система | Данные | TCP / SQL | Запись заказа | Регистрация заказа во внутренней системе |
| Бизнес-логика | Маркетплейс | Интерфейсы | HTTPS REST API | JSON | Обновление остатков и цен |
| Учетная система | Маркетплейс | Интерфейсы | HTTPS REST API | JSON | Передача статуса и трек-номера |
| Интеграционный модуль | Журнал мониторинга | Данные | TCP / HTTPS | JSON log | Контроль ошибок и результатов синхронизации |
