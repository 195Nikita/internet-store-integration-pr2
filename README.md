# Система агрегации и интеграции данных интернет-магазина
- загрузка остатков и цен из JSON-файла складской системы;
- проверка входящего заказа из webhook-сообщения;
- передача актуальных остатков через абстракцию REST API;
- сохранение принятого заказа через абстракцию учетной системы;
- разделение компонентов на адаптеры, бизнес-логику и модель предметной области;
- автономные smoke-тесты без сторонних библиотек.

## Структура

```text
├── src/       исходный код интеграционного модуля
├── config/    пример конфигурации подключений и импорта
├── tests/     исполняемые сценарии самопроверки
├── docs/      отчет, архитектура и таблица интеграций
└── samples/   тестовые входные данные
```

## Запуск

Требуется .NET SDK 8.0 или новее.

```bash
dotnet run --project src/InternetStoreIntegration
dotnet run --project tests/InternetStoreIntegration.SmokeTests
```

При обычном запуске заказ сохраняется в локальный файл `.runtime/orders.jsonl`. Этот каталог исключен из Git.

## Уровни интеграции

1. **Данные:** JSON/CSV/XML и запись в учетную систему.
2. **Интерфейсы:** HTTPS REST API и webhook-сообщения.
3. **Бизнес-логика:** валидация заказа, проверка остатков и подготовка данных к синхронизации.

Подробная схема находится в [docs/architecture.md](docs/architecture.md), а спецификация взаимодействий — в [docs/integration-matrix.md](docs/integration-matrix.md).
